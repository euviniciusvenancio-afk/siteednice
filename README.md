# Chinelos Lucrativos: página de amostra

Site estático (HTML, CSS e JS puros, sem build). Para publicar na Vercel ou na Netlify, importe este repositório e deixe as configurações padrão: sem comando de build e com a pasta raiz como diretório de publicação.

## Onde mudar as coisas
- `config.js`: cores, textos, número do WhatsApp, vídeo da prévia e a lista de arquivos (liberados e bloqueados).
- `style.css`: visual da página.
- `media/`: prévia curta (`previa-chinelo.mp4`) e aula completa comprimida (`videoaula-chinelo-leve.mp4`).
- `assets/amostras-novas/`: PDFs da amostra grátis.

Os materiais pagos **não** ficam neste repositório. As pastas bloqueadas da página só mostram os nomes dos arquivos.
